# ChatGPT 5.4 Frontend Skill — PolyGest

Adaptation of the supplied ChatGPT 5.4 Frontend Skill for the PolyGest repository.

- `SKILL.md`: workflow, design rules and mandatory PolyGest guardrails.
- `references/design-principles.md`: extended visual design guidance.
- `docs/POLYGEST_DESIGN_SYSTEM.md`: authoritative product design system.
- `docs/FRONTEND_SECURITY_STANDARD.md`: mandatory frontend security and privacy standard.

The original skill focuses on visual quality. This adaptation adds the controls required for a multi-tenant business application handling financial, payroll and personal data. Security, privacy, accessibility and approved product scope always take precedence over visual choices.

The skill can be installed in a Codex skills directory as `chatgpt-5-4-frontend-skill`. This repository copy does not automatically install it on a developer's machine.
